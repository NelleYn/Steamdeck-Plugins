# DeckPiP and the Decky Plugin Store

## Status

**Conditional**: one technical blocker is now solved, one policy
blocker remains.

## Hard blocker (policy)

The
[`plugin_addition.md` PR template](https://github.com/SteamDeckHomebrew/decky-plugin-database/blob/main/.github/PULL_REQUEST_TEMPLATE/plugin_addition.md)
requires:

> I confirm that the **majority** of this plugin's code was not
> generated by generative AI.

DeckPiP was written via AI pair programming, so it cannot truthfully
tick that box. Until the policy changes (or someone rewrites the
codebase by hand), the store will not accept it.

## Soft blocker (cleared / clearable)

### Public repo — done

The repository is public, so Decky's anonymous "Install plugin from
URL" works against the GitHub Release asset:

```
https://github.com/NelleYn/Steamdeck-Plugins/releases/download/dev/DeckPiP.zip
```

CI publishes this on every push to the feature branch.

### Pacman footprint — small, vendorable

Required pacman set is one package: `tigervnc`. Optional GameMirror
packages are three more, but a session without GameMirror runs
without them.

The remaining `tigervnc` could be vendored as a static build to drop
the pacman dependency to zero — out of scope for now.

## Soft requirements met

- `plugin.json` schema matches the upstream template.
- BSD-3-Clause license in `LICENSE` and `package.json`.
- Backend is plain Python on the `decky` runtime.
- Frontend builds with the upstream `@decky/rollup` preset.
- No telemetry. Optional self-update polls `api.github.com` only.
- `api_version: 1`, the current accepted value.
- No paid features, no required logins.

## Submission workflow (when ready)

1. Tag a public Release on GitHub with `DeckPiP.zip` attached (CI
   already does this on every push).
2. Fork `SteamDeckHomebrew/decky-plugin-database`.
3. Add DeckPiP as a git submodule under `plugins/DeckPiP`.
4. Open a PR using **plugin_addition** template, fill in:
   - Original-author confirmation.
   - License compliance.
   - **AI policy** — current blocker.
   - Backend type: "custom backend".
   - Tested-on-Stable / Tested-on-Beta confirmations.
5. Wait for community testers to leave test reports.
6. Reviewers merge, store updates.

## Until then

DeckPiP installs straight from this repository — three install paths
in the README (in-panel URL, one-shot curl, manual). The public repo
means anonymous install works in all three.
